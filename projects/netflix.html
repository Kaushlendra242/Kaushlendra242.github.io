Project Overview

Analyzes Netflix content and builds a content-based recommendation workflow using textual features and similarity.

Data Analysis

The project covers data cleaning, exploratory analysis, content trends, genres, ratings and other catalog characteristics.

Recommendation Approach

TF-IDF is used to represent textual content, followed by similarity calculations to identify related titles.

The project demonstrates how content metadata can support personalized discovery and recommendation experiences.
