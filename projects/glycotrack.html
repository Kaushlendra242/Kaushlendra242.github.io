PROJECT CASE STUDY

GlycoTrack — Diabetes Risk Prediction

Machine-learning portfolio application using XGBoost, SMOTE and Streamlit.

PythonXGBoostSMOTEMachine LearningStreamlit
View GitHub Repository ↗← Back to Projects

Project Overview

Builds a predictive analytics workflow for diabetes-risk classification, including preprocessing, feature engineering, class-imbalance handling, model evaluation and application deployment.

Problem

The project explores how structured health-related features can be used in a machine-learning classification workflow.

Methodology

The workflow includes exploratory analysis, preprocessing, feature engineering, imbalance handling with SMOTE, model training and evaluation.

Model Evaluation

Evaluation focuses on appropriate classification metrics such as recall and ROC-AUC, especially because identifying positive cases is important in an imbalanced classification setting.

Important Note

This is an educational portfolio project and is not a medical diagnostic tool. Predictions should not be used for clinical decision-making.
